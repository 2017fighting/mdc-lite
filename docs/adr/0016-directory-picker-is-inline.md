# 0016. 目录选择器是页内内联工作台，不是弹窗

- 状态：Accepted（修正「前端三视图原型」的补充裁决）
- 日期：2026-10-28
- 来源：wayfinder 票 #11 的补充裁决 → 原型重塑（`prototype/frontend-views` @ `f6d021c`）→ spec #17 修订

## 背景

#11 的补充裁决推翻了原型的「本机目录拖放」，定为**容器内目录选择器**：弹窗式浏览器（面包屑 + 子目录列表 + 手输路径 + 「设为根目录」/「加入排除」两个动作），可浏览范围 = 进程级 `browse_roots` 白名单。那条裁决解决的是**安全与路径来源**问题（不能拖本机路径、只认容器内绝对路径），这部分完全正确。

但交互形态在真机复核时出了问题：弹窗打断扫描页的操作流；而「设为根目录」这个措辞把「多根并存」这件事说成了单选；实际使用里用户要同时扫 `/media/2024` 与 `/media/vr`，并对若干子目录设排除。

## 决定

- **内联 Directory Deck**（页内，非弹窗）：面包屑 + 绝对路径手输**即时跳转** + 常用预设胶囊 + 子目录表（`dir-table`：目录名 / 包含内容统计 / 容器内完整路径 / 目录操作）。
- **多根并存**：可加入任意多个互不重叠的扫描目录；排除是独立清单。
- **四态 toggle**，措辞照原型、**废除「设为根目录」**：`+ 加入扫描` / `✓ 移出扫描`、`+ 排除` / `取消排除`（另有「将当前目录加入扫描」）。
- **双栏 Scope Ledger**：左「待扫描目录清单」、右「排除过滤清单（整树跳过）」，底栏汇总数量并标明受 `browse_roots` 白名单保护。
- **端点面完全不变**：仍是 `GET /api/fs/dirs?path=`（越界 400 `root_not_browsable`、不存在 404、只列目录、上限 200）。

## 不变量（沿用 #11，未改）

- 可浏览范围 = `browse_roots` 白名单；越界即拒。
- 只显示容器内绝对路径 + 挂载点标签；**不做**本机拖放与宿主路径映射。
- 排除是**整棵子树、不认 glob**，且必须是某个根的真子目录（就地报错）。
- 多根不得相同或嵌套（词法 Clean/Abs 比较、不解析 symlink）。

## 替代方案

- **(a) 保留弹窗式**：被否 —— 打断操作流；且「设为根目录」与多根并存的语义冲突。
- **(b) 弹窗但改多选**：被否 —— 面包屑导航在弹窗里仍然局促，而扫描页本身就有大块空白可以承载工作台。
- **(c) 直接在扫描表单里手输路径**：被否 —— 用户记不住容器内路径；预设胶囊与子目录表才是「不用记路径」的关键。

## 后果

- 扫描页承担了更多职责（目录工作台 + 范围清单），需要 `.table-wrap` 之类的溢出兜底。
- `browse_roots` 的 `label`（挂载点标签）在 Scope Ledger 的每一行都要显示 —— 这是它从字符串数组改成 `[{path, label}]` 对象数组的真正用途。
- 第二批的监控目录 CRUD 复用同一工作台与同一端点。
