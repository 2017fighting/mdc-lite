# 0003. 主干相同的重复版本交人判定，不自动合成一组

- 状态：Superseded by ADR-0019
- 日期：2026-10-27
- 来源：wayfinder 票「番号解析与文件分组规则」（#3）

## 背景

旗标（无码 `-U` / 中字 `-C` / 破解 / 流出）不进产物字段，所以剥掉旗标后 `ABC-123.mp4` 与 `ABC-123-U.mp4` 的主干相同；按相似度它们会被当成同一作品的两片，U 版被硬链成 `ABC-123-cd2.mp4`。

## 决定

主干相同而**两侧都没有生效分片标记** → `duplicate_stem` → 建 `needs_number` 任务，前端逐文件填号 + 「同一作品的分片」勾选。**不自动合成一组。**

## 替代方案

- **(a) 自动合成一组**（最简）：被否 —— 副本被静默当成分片。
- **(b) 内部保留版本键**（旧仓做法）：被否 —— README 明确不要旗标，且两版会争同一个 `{number}/` 输出目录。

## 后果

- 中字版/无码版并存的集合会出现在待补号列表里（宁可问一次，也不硬链副本）。
- 换掉这个取舍要动分组判据与产物契约。
