# Triage Labels

这些技能用五个规范化的 triage 角色说话。本文件把角色映射到本仓 tracker 实际使用的标签串。

| 技能里的标签 | 本仓 tracker 的标签 | 含义 |
| ------------ | ------------------- | ---- |
| `needs-triage` | `needs-triage` | 维护者需要评估这张 issue |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已完全定清，可交给 AFK agent |
| `ready-for-human` | `ready-for-human` | 需要人来实现 |
| `wontfix` | `wontfix` | 不做 |

当某个技能提到一个角色（例如「apply the AFK-ready triage label」），用上表里对应的标签串。
